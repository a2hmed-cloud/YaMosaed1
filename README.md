# يا مساعد (YaMosaed1)

مساعد صوتي مصري لأندرويد. وكيل بدون ذكاء اصطناعي: بيفهم الأوامر بقواعد عربية، ويشغّل الأداة المناسبة.

## القدرات
- الوقت والتاريخ، الطقس (مع حفظ مدينتك)
- منبه وتايمر (بيفضل شغال لو قفلت التطبيق)
- مهام يومك (سجل في يومي / اعرض يومي / امسح)
- خرائط للأماكن القريبة
- موسيقى: شغّل أغنية من سبوتيفاي أو ساوند كلاود، واختار أول نتيجة مطابقة بنفسه، وتحكم في أي مشغّل (وقف، التالي، السابق)

## إعداد الصلاحيات (مرة واحدة)
1. **الميكروفون**: بيتطلب من التطبيق.
2. **وصول الإشعارات**: الإعدادات ← الإشعارات ← وصول الإشعارات ← يا مساعد. عشان التحكم في الموسيقى.
3. **إمكانية الوصول**: الإعدادات ← إمكانية الوصول ← يا مساعد. عشان يختار الأغنية بنفسه في سبوتيفاي/ساوند كلاود.
4. **المنبهات الدقيقة**: لو طلب منك، اسمح بيها للتايمر.

## القيود
- تشغيل أغنية بالاسم تلقائيًا في سبوتيفاي بدون اختيار بيحتاج Spotify Premium + Web API. الحل الحالي بيفتح البحث ويختار الأغنية.
- ساوند كلاود مقفول لتسجيل تطبيقات جديدة في الـ API، فالحل الحالي بالـ UI.
- تويست ميوزك: مفيش API عام، بيفتح بحث على جوجل.
- الاختيار التلقائي بيعتمد على شكل الشاشة، ولو غيّر التطبيق التصميم ممكن يحتاج تعديل.

## البناء
GitHub Actions بيبني الـ APK عند كل push على `main` (انظر `.github/workflows/android-apk.yml`).
